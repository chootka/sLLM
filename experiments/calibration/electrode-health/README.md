# Electrode health

## Plain English

Before blaming the organism for a reading, check the instrument. Short the
leads together and record: whatever moves is the amplifier, not the dish.

## Result

- Shorted-lead test 2026-08-24, 27 min. Drift ch0 +0.025, ch1 +0.004,
  ch2 +0.031 mV. Flat.
- Tips checked 2026-08-20, all three clean.
- Noise floor 0.02-0.10 mV per sample at 8 SPS, against 0.7-2.8 mV before the
  data rate was fixed 2026-08-22.

## Follow-on

Re-plating the electrodes is not indicated while the shorted test is flat.
A foil shield is not indicated: in-solution noise is at or below the shorted
floor, and 8 SPS already notches 50/60 Hz.
